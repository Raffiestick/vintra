# **App Name**: RizeUp Portal

## Core Features:

- Landing Page: Landing page with welcome message, description of the RizeUp Dealer CRM, and clear CTAs for login and registration.
- Authentication System: Firebase Authentication system enabling registration, login, and forgot password functionality using email and password.
- Role-Based Registration: Multi-role registration form allowing users to register as Dealer, Staff, Admin, Finance, or Title Clerk.
- Admin Approval Panel: Admin-only approval panel to approve or reject pending registrations.
- Role-Based Dashboard: Role-based dashboards displaying a welcome message tailored to the user's role after authentication and approval.

## Style Guidelines:

- Primary color: Dark purple (#6246EA) to convey elegance and sophistication, in line with the desired MYLO style.
- Background color: Very dark gray (#1E1E1E) for a sleek, dark theme, providing a modern look and feel.
- Accent color: Lavender (#D4CFFF) to highlight key elements and CTAs, creating a visually appealing contrast against the dark background.
- Body and headline font: 'Inter' sans-serif for a modern, neutral, and professional look; great for both headlines and body text.
- Implement large rounded cards and generous spacing to match the sleek and modern branding aesthetics.
