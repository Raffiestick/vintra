# **App Name**: AuthFlow

## Core Features:

- Landing Page: Landing page with prominent Login and Register buttons.
- Auth Modal: Modal window for Login and Register, with toggle tabs to switch between forms.
- Registration Form: Register form collecting full name, email, password, and role (dropdown options: Admin, Dealer, Staff, Finance, Title Clerk).
- Login Form: Login form supporting email/password sign-in.
- Firebase Authentication: Secure email/password authentication powered by Firebase Auth.

## Style Guidelines:

- Dark color scheme to evoke a sense of modernity and sophistication. Primary color: Electric Violet (#A259FF), symbolizing creativity and wisdom.
- Background color: Soft Black (#1A1A1A), creating a clean, professional backdrop.
- Accent color: Neon Pink-Purple (#FF5CFF) for interactive elements and highlights.
- Text color: Light Gray (#D1D1D1) for readability.
- Button Hover: Deep Purple (#7A40FF).
- Error: High-contrast Red (#FF4D4D) for alerts.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, providing a modern, techy feel, and 'Inter' (sans-serif) for body text, ensuring readability and a neutral aesthetic.
- Use simple, outline-style icons for form fields and buttons to maintain a clean and modern look.
- Clean and minimalistic layout with ample spacing to improve readability and user experience. Use a grid system for consistent alignment.
- Subtle transitions and animations on button hovers and modal appearances to add a touch of interactivity.
