# **App Name**: RizeUp Dealer Connect

## Core Features:

- Dealer Authentication: Securely authenticate dealers using username/password or OAuth.
- Modal-based Login UI: Clean, accessible authentication via a modal, incorporating tabbed sign-in/sign-up.
- Content Generation Tool: AI-powered content generation tool to assist dealers in creating compelling marketing materials.

## Style Guidelines:

- Primary color: Deep violet (#7957D6) to convey sophistication and trustworthiness.
- Background color: Dark grey (#28292C) for a modern, professional dark theme.
- Accent color: Electric purple (#BE1DE5) for interactive elements and highlights.
- Font: 'Inter', a sans-serif font, for clean and accessible typography.
- Minimalist line icons for intuitive navigation.
- Clean, grid-based layout for optimal content presentation.
- Subtle transition animations on UI elements for a smooth user experience.
