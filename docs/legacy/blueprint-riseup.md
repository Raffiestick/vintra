# **App Name**: RizeUp Powersports Manager

## Core Features:

- Dashboard Overview: Dashboard to visualize key metrics, such as total inventory value, units sold this month, and outstanding invoices.
- Invoice Auto-Fill: Invoice Data Extraction tool: Upload invoices (auction, freight, etc.) and automatically extract data fields using OCR and AI to fill relevant Unit and Purchase Invoice fields.
- Unit Tracking: Unit Management: Create, view, edit, and track individual powersports units with details on acquisition, costs, title status, and sale information.
- Invoice Records: Purchase Invoice Management: Upload, record, and link purchase invoices (auction, freight, etc.) to corresponding unit records for accurate cost allocation.
- Title Management: Title Tracking: Monitor the status of titles for each unit, from acquisition to transfer.
- Financial Reporting: Reporting: Generate reports on inventory, sales, profitability, and title status. Filterable by date range and other relevant criteria.

## Style Guidelines:

- Primary color: Dark blue (#3B5998) to convey trust and reliability in financial management.
- Background color: Light gray (#F0F2F5) for a clean, professional interface.
- Accent color: Teal (#008080) for highlighting key actions and important data points.
- Body and headline font: 'Inter' sans-serif for a modern and readable interface.
